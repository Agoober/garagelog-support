# GarageLog Support

Support and privacy pages for **GarageLog**, the car maintenance, fuel and cost tracker for iPhone and iPad.

- **Support & FAQ:** https://agoober.github.io/garagelog-support/
- **Privacy policy:** https://agoober.github.io/garagelog-support/privacy.html

Need help? [Open a request](https://github.com/Agoober/garagelog-support/issues/new/choose).
Requests are public, so please don't include personal information.

## Editing the site

Plain HTML served by GitHub Pages from the `main` branch root — no build step.

| File | Page |
| --- | --- |
| `index.html` | Support & FAQ |
| `privacy.html` | Privacy policy |
| `assets/style.css` | Shared styles (light & dark) |

When the privacy policy changes, update the dates at the top. Keep FAQ paths
(e.g. "Settings › Reminders") in sync with the app's labels.
